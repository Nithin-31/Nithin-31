# 💫 About Me:
Well I’m a Senior Java Full Stack Developer with good experience building enterprise applications across various domains like banking and healthcare.<br>I primarily use Java and Spring boot for backend development and for frontend, I have used React and Angular.<br><br>Currently, I’m working at Morgan Stanley on a Chargeback and Dispute Platform, so basically this helps customers to raise disputes for card transactions and automates the process of validation, collection and resolving claims.<br><br>Here my day to day work involves building Spring Boot microservices and React dashboards to manage the transaction workflows and we are using  Kafka for asynchronous communication between different services. Coming to database, we are storing the transaction data in Postgres and MongoDB for storing dispute metadata. Later, we deploy our services on AWS cloud using Docker and Kubernetes by automating CICD pipelines using Jenkins.<br><br><br><br><br><br><br><br><br><br><br><br><br>
